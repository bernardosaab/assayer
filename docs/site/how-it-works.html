How Assayer works

One attempt of one case, from claim to grade. The model only proposes; every box with a purple border is a gate in code it cannot talk its way past. Back to the reports

gate in codemodel (proposes)stop path

Then the loop

1. Run with repeats

pass^k (every repeat passes) is reliability; pass@k is capability. A gap between them is its own diagnosis.

2. Read failures

Failure causes are counted by check and rubric line; the report shows each transcript, tool call and quoted finding.

3. Fix either side

The agent (prompt, tool, data) or the harness (check, rubric, scenario, gold). A production failure becomes a scenario file.

4. Compare paired

Same cases, discordant pairs, exact McNemar, the flipped cases, and the smallest change the sample can resolve.

5. Replay to attribute

Re-score stored outputs with current graders and zero agent calls: did the agent change, or the grading?
